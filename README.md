# Sai Sugun D R · Portfolio

Static HTML, CSS and JavaScript. No install or build step.

## GitHub Pages

Extract the ZIP and copy its contents into your existing Pages publishing folder.
Keep index.html, .nojekyll, the scripts, styles and assets/ at that folder's top level.
Keep the repository name, Pages source and any existing CNAME unchanged to retain your URL.

## Local preview

Run `python -m http.server 8000` from this folder and open http://localhost:8000/.
Use an HTTP server; opening index.html directly does not load JavaScript modules.

## Editing

Profile and projects: content.js. Development stages: journey-content.js.
Keep the licence and credit files in assets/.

Run `node --test` (Node.js 24) to check project content and internal links.
When publishing changes, refresh the version query in index.html and affected module imports so returning visitors receive the updated files.
